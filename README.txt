AlgoVisual ID - Prototype (modul Sorting: Bubble Sort)

Compile & jalankan:
  cd src
  javac *.java
  java Main

Isi:
  Main.java         - jendela utama (tab)
  SortingPanel.java - GUI, tombol Next Step/Auto Play, gambar bar
  BubbleSort.java   - algoritma, mencatat tiap langkah ke list
  Step.java         - data satu langkah
  Helper.java       - parsing input (split, trim, parseInt) + teks penjelasan

Belum ada: Selection/Insertion Sort, Searching, Stack/Queue, Kuis, Mode Bandingkan.
